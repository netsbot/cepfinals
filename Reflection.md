# Project Reflection: Hive Collapse

### **Total Contributions**
I architected the core technical foundations of *Hive Collapse*. My key contributions include engineering our custom zero-dependency TypeScript Entity Component System (ECS) using Sparse Sets and bitmask queries, building the 4-step Cellular Automata procedural cave generator with flood-fill room extraction, and implementing our role-biased Genetic Algorithm evolution engine for MOBA enemy archetypes (Slashers, Shooters, Tanks). Additionally, I developed the combat mechanics—5-bullet magazine, ranged kill refills, 75° right-click melee slash arc, and 20% lifesteal—along with the 360° raycasting Fog of War line-of-sight system and responsive DOM dashboard UI.

### **Learned Concepts & Self-Growth**
Technically, I mastered cache-friendly data structures like Sparse Sets and bitwise query matching, realizing how memory layout impacts real-time performance far more than classic OOP hierarchies. Conceptually, I learned how balancing pre-luck transparency with post-luck variance creates rewarding strategic depth.

### **Teamwork Insights**
I learned that clear architectural boundaries, strict TypeScript interfaces, and disciplined Git commit workflows are vital for seamless team integration and avoiding integration bottlenecks.
